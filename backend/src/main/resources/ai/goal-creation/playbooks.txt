# 카테고리별 목표 설계 가이드.
# "### 키" 아래 내용이 그 카테고리 목표의 계획 요청에 [카테고리 가이드]로 붙는다 (# 로 시작하는 줄은 주석).
# 키 = GoalSubType 이름. 기타(HEALTH_OTHER, LEARNING_OTHER, OTHER)와 종류 미지정은 해당 1단계 가이드(HEALTH, LEARNING, HABIT, ETC)를 쓴다.
# 각 가이드: 꼭 알아야 할 것(인터뷰) / 루틴 / 세부 목표 / 수치 / 일회성 Task / 만들지 말 것
# 루틴은 하나에 5~30분. 긴 세션은 "내용이 다른" 루틴으로 나누고, 같은 활동을 시간만 바꿔 두 개 만들지 않는다.
# 강도를 올리는 계획은 새 루틴이 아니라 그 루틴 description 에 "3주차부터 30분" 처럼 적는다.

### EXERCISE
꼭 알아야 할 것: 운동 경험(처음/쉬다 다시/꾸준히), 운동 장소(헬스장/집/야외), 주 몇 회 가능한지, 아픈 곳.
루틴: 실제 운동 세션이 루틴이야. 분할(예: 주 3회 전신, 주 4회 상·하체 분할)을 정해서 요일별 세션을 루틴으로 만들어.
  - 한 루틴은 30분 이하. 1시간 운동이면 내용이 다른 두 루틴으로 나눠 같은 요일에 이어서 (예: "하체 근력 30분" + "유산소 20분").
  - 제목은 세션 이름 + 시간 (예: "하체 근력 30분", "상체 근력 30분", "인터벌 러닝 20분").
  - description 에 종목·세트·횟수·휴식을 구체적으로 (예: "스쿼트 4x10, 루마니안 데드리프트 3x10, 런지 3x12(각), 레그프레스 3x12, 휴식 60~90초").
  - 초보는 머신·맨몸 위주, 첫 2주는 가벼운 무게. 강도 올리기는 description 에 (예: "3주차부터 세트 4개, 무게 5% 증가").
세부 목표: 근력 / 유산소 처럼 운동 영역으로 1~2개. metric 예: 주간 운동 횟수 GTE 3 WEEKLY.
수치(goal.metric): 사용자가 말한 기록(벤치프레스 kg, 5km 기록 분, 턱걸이 개수)이 있으면 그걸로.
일회성 Task: 거의 없음. 넣는다면 "5km 기록 측정", "1RM 측정" 같은 측정만, 마일스톤 시점에.
만들지 말 것: 운동화·운동복 구매, 운동 영상 찾기, 헬스장 알아보기, 운동 계획 세우기, 스트레칭 영상 찾기.

### DIET
꼭 알아야 할 것: 현재 체중·목표 체중·기간, 운동 가능 여부(헬스장/집), 식습관 문제(야식, 폭식, 외식, 음주), 하루 식사 패턴.
루틴: (1) 운동 세션 루틴 — 근력 2~3회 + 유산소. 제목은 세션 이름 + 시간, description 에 종목·세트·횟수 (EXERCISE 와 같은 방식).
      (2) 식단 기록 루틴 — "식단 기록 5분" 매일 저녁. description 에 그날 지킬 식단 원칙 체크 항목.
      (3) 주 1회 "공복 체중 재기 2분" (월요일 아침 등) — 진행 그래프 기록용.
세부 목표: "식단" 과 "운동" 2개. 식단 세부 목표 description 에 구체적인 식단 원칙을 넣어:
  하루 목표 섭취량(대략 체중×22~25kcal 에서 300~500kcal 적게), 단백질(체중×1.2~1.6g), 끼니 구성 예시(아침: 그릭요거트+견과, 점심: 일반식 밥 2/3, 저녁: 닭가슴살·두부+채소),
  피할 것(야식, 단 음료, 술)을 한두 문장으로. 식단 metric 예: 하루 섭취 kcal LTE DAILY, 또는 식단 지킨 날 GTE 5 WEEKLY.
수치(goal.metric): 체중 kg. 감량 속도는 주 0.5~1kg, 월 2~4kg 이내로.
일회성 Task: 거의 없음.
만들지 말 것: 저칼로리 식재료 구매, 장보기, 식단 앱 설치, 운동화 끈 조정, 레시피 찾기, 체중계 사기.

### WATER
꼭 알아야 할 것: 지금 하루에 마시는 양, 목표 양, 하루 일과(출근·수업 시간).
루틴: 마시는 시점에 붙인 짧은 루틴 2~3개 (예: "기상 직후 물 한 컵 1분", "점심 후 물 500ml 1분"), 그리고 "하루 물 섭취 체크 2분" 저녁.
  목표량을 늘려가야 하면 description 에 단계별로 적어 (예: "1~2주 1.2L → 3주차부터 1.6L").
세부 목표: 1개 ("하루 물 마시기", metric: 하루 섭취 ml GTE DAILY).
수치(goal.metric): 하루 물 섭취량 ml (시작값 = 지금 마시는 양).
일회성 Task: 없음.
만들지 말 것: 물병 구매, 물 마시기 앱 설치, 알람 설정하기.

### NO_ALCOHOL
꼭 알아야 할 것: 지금 음주 빈도·양, 목표(완전 금주 / 주 1회 이하 등), 술 마시게 되는 상황(회식, 스트레스, 혼술).
루틴: "금주 체크 1분" 매일 밤(마셨으면 양 기록). 술 마시던 요일·시간에 대체 행동 루틴 1개 (예: 금요일 저녁 "산책 20분", "탄산수+간식 타임 10분").
세부 목표: 1~2개 (금주 유지, 대체 습관). metric 예: 음주한 날 LTE 1 WEEKLY.
수치(goal.metric): 연속 금주 일수 또는 주간 음주 횟수 (시작값 = 지금).
일회성 Task: 꼭 필요할 때만 (예: 회식 전날 "거절 멘트 정하기 5분" 은 만들지 마 — description 에 적어).
만들지 말 것: 술 버리기, 금주 앱 설치, 금주 관련 영상 찾기.

### NO_SMOKING
꼭 알아야 할 것: 하루 흡연량, 금연 시작일(바로/날짜), 담배가 당기는 상황(식후, 커피, 스트레스, 출근길), 금연 보조제 사용 의향.
루틴: "금연 체크 1분" 매일 밤(피운 개비 수 기록). 당기는 시간대 대체 행동 루틴 1~2개 (예: 점심 후 "양치·물 마시기 3분", 출근길 "심호흡 5분").
  줄여가는 방식이면 체크 루틴 description 에 주차별 하루 허용 개비를 적어 (예: "1주 10개비 → 2주 6개비 → 3주 0개비").
세부 목표: 1~2개. metric 예: 하루 흡연 개비 LTE DAILY.
수치(goal.metric): 하루 흡연량(개비) 감소형, 또는 연속 금연 일수.
일회성 Task: "보건소 금연클리닉 등록" 처럼 실제 효과가 큰 1개까지만 허용 (사용자가 원할 때).
만들지 말 것: 라이터 버리기, 금연 앱 설치, 금연 정보 찾아보기.

### LANGUAGE
꼭 알아야 할 것: 언어·현재 수준, 목표 형태(시험 점수/회화/여행), 시험이면 시험일, 하루에 쓸 수 있는 시간.
루틴: 영역별 공부 세션 (예: "단어 30개 15분" 매일, "LC 파트 3·4 30분" 주 3회, "쉐도잉 15분", "회화 스크립트 소리내 읽기 20분"). description 에 교재·범위·방법.
세부 목표: 영역별 1~3개 (어휘 / 듣기 / 말하기·독해). metric 예: 주간 학습 시간 GTE 180 WEEKLY 분, 외운 단어 GTE 150 WEEKLY.
수치(goal.metric): 시험 점수(현재 점수를 말했을 때만), 또는 누적 학습 시간·외운 단어 수.
일회성 Task: 시험 접수, 모의고사 실전 풀이(120분) 같은 실제로 시간을 내야 하는 것만, 마일스톤 시점에.
만들지 말 것: 교재 구매, 단어 앱 설치, 공부 계획 세우기, 인강 찾아보기.

### CERTIFICATE
꼭 알아야 할 것: 자격증 이름, 시험일(접수 마감), 현재 공부 상태, 하루 공부 가능 시간.
루틴: 과목·단원별 공부 세션 (예: "필기 1과목 이론 30분", "기출 20문제 30분", "오답 정리 15분"). 시험 2~4주 전부터 기출 비중을 늘린다고 description 에.
세부 목표: 필기/실기 또는 과목별 1~3개. metric 예: 기출 회차 GTE 2 WEEKLY.
수치(goal.metric): 모의고사 점수 또는 푼 기출 회차 수(누적형 시작값 0).
일회성 Task: 시험 접수(접수 기간에 맞춰), 실전 모의고사 1회(시간 재고), 시험 응시. 그 외 금지.
만들지 말 것: 교재 구매, 강의 알아보기, 공부 계획 세우기, 시험 정보 검색.

### READING
꼭 알아야 할 것: 목표 권수·기간, 읽고 싶은 분야, 읽는 시간대(출퇴근, 자기 전).
루틴: "독서 20분" 을 정해진 시간대에 (자기 전, 출퇴근). 주 1회 "한 줄 기록 5분" 정도만.
세부 목표: 1개 (꾸준한 독서). metric 예: 주간 독서 시간 GTE 120 WEEKLY 분, 또는 읽은 쪽수.
수치(goal.metric): 읽은 책 권수 (startValue 0, 누적).
일회성 Task: 없음.
만들지 말 것: 책 고르기, 책 구매, 서점·도서관 가기, 독서 앱 설치, 독서 계획 세우기.

### CODING
꼭 알아야 할 것: 배우려는 것(언어·분야·포트폴리오/코테/취업), 현재 수준, 하루 가능한 시간, 결과물 목표.
루틴: 실제 코딩 세션 (예: "알고리즘 1문제 30분" 주 4회, "프로젝트 기능 구현 30분" 주 3회, "강의 따라치기 25분"). description 에 범위·난이도(예: 백준 실버 → 골드).
세부 목표: 기초 학습 / 문제 풀이 / 프로젝트 중 1~3개. metric 예: 푼 문제 GTE 8 WEEKLY.
수치(goal.metric): 푼 문제 수, 완성한 기능 수, 커밋 일수 등 누적형.
일회성 Task: 마일스톤 결과물만 (예: "포트폴리오 1차 배포", "모의 코딩테스트 120분").
만들지 말 것: 개발 환경 설치, 강의 찾아보기, 노트북 정리, 공부 계획 세우기.

### WAKE_UP
꼭 알아야 할 것: 지금 기상 시각, 목표 기상 시각, 지금 취침 시각, 출근·등교 시각.
루틴: "목표 시각 기상 체크 1분" 매일 (기상 시각을 1~2주 간격으로 15~30분씩 당기는 일정은 description 에). 기상 직후 할 짧은 행동 1개 (예: "기상 후 햇빛 보며 물 마시기 5분").
  일찍 일어나려면 취침도 당겨야 하므로 "취침 준비 15분" 루틴을 같이.
세부 목표: 1~2개 (기상 / 취침). metric 예: 목표 시각 기상한 날 GTE 5 WEEKLY.
수치(goal.metric): 주간 목표 기상 성공 일수 또는 null.
일회성 Task: 없음.
만들지 말 것: 알람 앱 설치, 알람 맞추기, 암막커튼 구매, 수면 정보 찾아보기.

### SLEEP
꼭 알아야 할 것: 지금 취침·기상 시각, 목표 취침 시각, 잠들기 전 습관(휴대폰, 야식, 카페인).
루틴: "취침 준비 루틴 15분" 매일 (목표 취침 30분 전: 휴대폰 충전기에 꽂기·조명 낮추기·스트레칭 — description 에). "취침 시각 체크 1분" 다음 날 아침.
  취침 시각을 15~30분씩 당기는 일정은 description 에.
세부 목표: 1~2개. metric 예: 목표 시각 전 취침 GTE 5 WEEKLY.
수치(goal.metric): 주간 성공 일수 또는 null.
일회성 Task: 없음.
만들지 말 것: 수면 앱 설치, 침구 구매, 수면 정보 찾아보기.

### MEDITATION
꼭 알아야 할 것: 명상 경험, 하고 싶은 시간대, 목적(스트레스, 집중, 수면).
루틴: "호흡 명상 5분" 매일 정해진 시각에. 시간을 늘리는 일정(5 → 10 → 15분)과 방법을 description 에(4초 들이쉬고 6초 내쉬기, 바디스캔 등).
세부 목표: 1개. metric 예: 명상한 날 GTE 5 WEEKLY.
수치(goal.metric): 누적 명상 일수 또는 null.
일회성 Task: 없음.
만들지 말 것: 명상 앱 설치, 명상 영상 찾기, 방석 구매.

### CLEANING
꼭 알아야 할 것: 공간(방·집 전체), 지금 상태, 청소 가능한 요일·시간.
루틴: 매일 짧게 "10분 정리"(바닥에 있는 물건 제자리), 주 1~2회 구역별 청소 (예: "토요일 욕실 청소 20분", "수요일 주방 정리 15분"). description 에 그날 할 구역과 순서.
세부 목표: 1~2개 (매일 정리 / 주간 청소). metric 예: 정리한 날 GTE 5 WEEKLY.
수치(goal.metric): null 이 보통.
일회성 Task: 대청소·버리기처럼 한 번에 크게 해야 하는 것 1~2개만 (예: "옷장 안 입는 옷 비우기 40분").
만들지 말 것: 청소용품 구매, 수납함 사기, 청소 방법 찾아보기.

### JOURNAL
꼭 알아야 할 것: 쓰고 싶은 일기 형태(감사·회고·감정), 쓰는 시간대, 기록 도구(앱/노트).
루틴: "일기 10분" 매일 자기 전 (처음 2주는 "세 줄 일기 5분"). description 에 질문 템플릿 (오늘 잘한 일 1개 / 아쉬운 점 1개 / 내일 할 1가지).
  주 1회 "한 주 돌아보기 15분".
세부 목표: 1개. metric 예: 일기 쓴 날 GTE 5 WEEKLY.
수치(goal.metric): 누적 작성 일수 또는 null.
일회성 Task: 없음.
만들지 말 것: 노트 구매, 일기 앱 설치, 일기 쓰는 법 찾아보기.

### SAVING
꼭 알아야 할 것: 목표 금액·기간(또는 줄이고 싶은 지출 항목과 한도), 한 달 수입이 들어오는 날(월급일·용돈일), 지금 한 달에 모으는 돈, 돈이 새는 곳(배달, 카페, 쇼핑, 구독).
루틴: (1) "가계부 쓰기 5분" 매일 저녁 — description 에 그날 지출 기록 + 지킬 원칙 체크 (예: "배달 주 2회 이하, 카페 하루 1잔").
      (2) "주간 지출 점검 10분" 주 1회 (일요일 저녁 등) — 이번 주 지출을 한도와 비교하고 다음 주 한도 정하기.
      (3) 무지출 데이를 원하면 요일을 정해 "무지출 데이 체크 1분" 루틴. 금액을 늘려가야 하면 description 에 "2개월차부터 월 60만 원" 처럼.
세부 목표: 모으기 / 지출 줄이기 1~2개. 지출 세부 목표 description 에 항목별 한도를 숫자로 (예: "식비 월 40만 원, 배달 월 8만 원, 구독 2개 이하").
  metric 예: 주간 지출 LTE 15 WEEKLY (만 원), 무지출 데이 GTE 2 WEEKLY.
수치(goal.metric): 모은 금액 만 원 (startValue = 지금 모아 둔 돈 또는 0, 누적 증가형). 지출 줄이기 목표면 한 달 지출 만 원 감소형.
  목표가 기간 대비 무리하면(한 달 수입보다 많이 모으기 등) 금액이나 기간을 현실적으로 조정하고 이유를 적어.
일회성 Task: 월급일 "적금·자동 이체 금액 조정 10분", 마일스톤 시점 "한 달 결산 15분" 처럼 날짜가 정해진 것만.
만들지 말 것: 가계부 앱 설치, 재테크 정보 찾아보기, 주식·코인 투자, 통장 개설 알아보기, 예산 계획 세우기.

### HEALTH
루틴 위주로, 몸으로 직접 하는 행동(운동 세션, 섭취·체크, 대체 행동)만 루틴으로 만들어. description 에 구체적인 방법·양·강도.
세부 목표는 1~2개, 일회성 Task 는 측정·예약처럼 꼭 필요한 것만.
만들지 말 것: 물건 구매, 앱 설치, 정보·영상 찾기, 계획 세우기.

### LEARNING
루틴 위주로, 실제로 공부·연습하는 세션만 루틴으로 만들어 (범위·분량·방법을 description 에).
일회성 Task 는 시험 접수·모의고사·결과물 제출처럼 날짜가 정해진 것만.
만들지 말 것: 교재·강의 구매, 자료 찾아보기, 앱 설치, 공부 계획 세우기.

### HABIT
매일 같은 시각에 하는 짧은 루틴(1~15분) 1~3개가 핵심이야. 습관이 붙으면 시간·강도를 조금 올리는 일정을 description 에 적어.
일회성 Task 는 거의 만들지 마.
만들지 말 것: 물건 구매, 앱 설치, 정보 찾아보기, 계획 세우기.

### ETC

만들지 말 것: 준비물 구매, 정보 찾아보기, 앱 설치, 계획 세우기.
